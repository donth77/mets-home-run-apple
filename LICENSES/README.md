# License Selection Required

No reuse license has been granted yet. Add explicit license texts before the first public push or release.

The maintainer should choose licenses independently for:

- software and firmware source;
- hardware/CAD source;
- documentation;
- each model, texture and other visual asset.

Third-party assets keep their own licenses and require an asset manifest. A repository-level software license never grants rights to team/league marks or separately identified assets.
