# Pixel Operator 8 Bold

Pixel font by Jayvee Enaguas (HarvettFox96), released under CC0 1.0 Universal
(see `LICENSE.txt`). This is the font the display firmware and the animation
preview build with by default.

Local builds may substitute a different font. The generator writes those
variants as `*.local.*` files, which are gitignored so derived assets do not
enter the repository.
